# Security scope

This experimental port uses an older prebuilt MediaTek SDK. It does not provide
MQTT TLS or HTTPS OTA, and OTA checksums are not signatures. Operate it on a
trusted local network; do not expose management interfaces to the Internet.

Report fork-specific vulnerabilities privately to the repository owner using
GitHub private vulnerability reporting when enabled, or a private contact listed
on the owner's profile. Do not include credentials or pairing keys in public
issues. No security-response SLA or supported-release series is offered.

Issues demonstrably affecting unmodified upstream Tasmota can also follow the
[upstream security policy](SECURITY.upstream.md).
